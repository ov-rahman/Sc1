# UI и шрифты

---

## Принцип

**Весь интерфейс — железнодорожная документация.**

Не «стилизован под», а **является**: билет, ведомость, наряд,
табло, опись. Игрок не открывает «меню» — он достаёт бумажку.

---

## Шрифты

| Где | Шрифт | Комментарий |
|---|---|---|
| Диалоги | моноширинный пиксельный, 8×16 | эстетика ж/д табличек |
| [[Расписание]] / [[Контролёр]] | **сплит-флап** | буквы перещёлкиваются со звуком |
| [[Дрезя]] | тот же, **КАПС** | без запятых |
| Дневник [[Яр]]а | **рукописный** | деградирует к акту V |
| Документы [[Линия|Линии]] | машинописный (пишущая машинка) | с проваленными литерами |
| Выговоры [[Стрелочник Виноват\|Виноватого]] | бланк + рукописная вставка | |
| Заголовки актов | сплит-флап | |
| Титры | машинописный | |

**UI-слой рендерится в 1×**, не масштабируется вместе с игрой.
Текст чистый и читаемый на любом разрешении.

## Экран боя

```
  ┌────────────────────────────────────────────────────┐
  │              [ПРОТИВНИК]                           │
  │         ТЕРПЕНИЕ  ████████░░░░░░                   │
  │                                                    │
  │  ┌──────────────────────────────┐   ┌───────────┐  │
  │  │      ОКНО УКЛОНЕНИЯ          │   │   СВЕТ    │  │
  │  │           ▪                  │   │    🟡     │  │
  │  └──────────────────────────────┘   └───────────┘  │
  │                                                    │
  │  БИЛЕТ  ● ● ● ○ ○ ○ ○ ○ ⊗ ⊗        ◻ 14           │
  │  [ГОВОРИТЬ] [ДЕЛО] [ГУДОК] [ЗАПИСАТЬ] [УЙТИ]      │
  └────────────────────────────────────────────────────┘
```

### Билет

**Не полоска здоровья.** Кружочки-компостерные отверстия:

```
    ○  целое
    ●  пробито
    ⊗  мёртвый прокол (навсегда)
```

Рисуется как настоящий билет: рамка, сетка, поля «ОТКУДА» / «КУДА»,
номер вагона и места.

**Поле «КУДА» заполнено маминым почерком.** Видно всегда.
Игрок читает это на каждом экране боя пятнадцать часов
и вспоминает в акте VII.

### Терпение

Полоса. Подписана `ТЕРПЕНИЕ`, а не HP.

У [[Контролёр]]а — **пустая серая полоса без делений**, которая
не движется. У [[Проводник]]а — так же.

### Кнопки действий

Стиль — **штампы на документе**. Прямоугольные, с рамкой,
как графы в бланке.

Недоступное действие — **серое с подписью причины**:
```
    [ЗАПИСАТЬ]  (ты не знаешь имени)
    [ГОВОРИТЬ]  (на тебя смотрят)
```

Причина всегда указана. Игра **никогда** не блокирует молча.

## Полевой HUD

### [[Яр]]

```
    ВОДА      ███████░░░  1.4 л
    ЖАР       ██████████
    ПОПУТЧИК  ███░░░░░░░  31      ← акты I–III
    ─────────────────────────
    ЗАБИТО КОСТЫЛЕЙ:  1 847
```

Счётчик костылей — **единственный постоянный элемент**, который
никогда не исчезает и никогда не убывает.

Он появляется в [[Акт III — Вера]] и остаётся до титров.

### [[Тим]]

```
    ВНИМАНИЕ  ███████░░░  71
    ◻ 14
```

**ВНИМАНИЕ** визуализируется дополнительно: при высоком значении
по краям экрана появляются **силуэты смотрящих**. Не персонажи —
намёки, тёмные пятна на периферии.

При 100 их около двадцати. При 1812 (акт VI) — весь экран в них.

## Ведомость

Отдельный экран. Разлинованная тетрадь.

```
   ВЕДОМОСТЬ                             31 / 187

   1   ПЕСОЧНИЦА                    ....... вписана
   2   ДРЕЗЯ  001                   ....... вписана
   ...
   5   ~~~~~~~~~~~~~~~~~~           ....... вычеркнут
   ...
   32  ______________
```

- Вписанные — **чернилами**, тем шрифтом, которым игрок набрал.
- Вычеркнутые — **зачёркнутая строка без имени**.
  Ты видишь, что кто-то был. Ты не помнишь, кто.
- Пустые — точки.

Ввод имени — **вручную, по букве**. 8–15 секунд на имя.
Это ритуал, а не ввод данных.

## Инвентарь

Не сетка. **Опись багажа.**

```
   ПРИ СЕБЕ

   Билет (детский)                    1
   Рюкзак                             1
   Печенье, полпачки                  1     ← нельзя съесть
   Заколка                            1
   Фонарик-брелок                     1
   Ключ от квартиры                   1
   Перо                               1
   Шарф (от Зои)                      1
   Билет Зои (недействителен)         1

   ДЛЯ ЯРА                            [4]
```

Вкладка `ДЛЯ ЯРА` — отдельная. Механической пользы нет.
12 слотов. В [[Акт VI — Горловина]] брат это увидит.

У [[Яр]]а после [[Акт V — Раскол]] в описи может появиться строка,
которую нельзя убрать:

```
   ВОДА                             3.0 л
   ВОДА (?)                         1.0 л     ← [[Капля]]
```

## Меню

Стилизовано под **расписание движения**:

```
   ОТПРАВЛЕНИЕ            ПУТЬ    ВРЕМЯ
 ▸ ПРОДОЛЖИТЬ               1     — : —
   НОВАЯ ИГРА               2     — : —
   ВЕДОМОСТЬ                3     — : —
   НАСТРОЙКИ                4     — : —
   ВЫХОД                    —     — : —
```

После [[Концовка — Нулевой километр]] первым пунктом появляется:
```
 ▸ ПРОДОЛЖИТЬ СИДЕТЬ        0     — : —
```

## Настройки

Раздел **«Режим Проводника»** — [[Кривая сложности#Режим Проводника]].
Доступен с первой минуты, без блокировок.

И одна строка внизу, без предупреждений:

```
    Сбросить память Ведомости.
    (Это можно. Мы не будем спорить.)
```

---

## Правила

1. **Ни одного элемента без диегетического объяснения.**
   Если UI нельзя объяснить фразой персонажа — переделываем.
2. **Ни одного счётчика, который игра не показала бы в мире.**
3. **Никаких всплывающих подсказок** с картинками кнопок,
   кроме первых десяти минут.
4. **Никаких маркеров квестов на карте.** Карта — рисунок
   [[Начальник Точки|Начальника Точки]] от руки, неточный.
5. **Кнопка пропуска не работает** в шести местах игры.
   Они перечислены в [[Правила письма диалогов]].
