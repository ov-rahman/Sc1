# АКТ IV — ГУДОК

**~1.8 ч. Порядок: ТИМ ▸ ЯР ▸ ОБА.**
Эмоциональный пик первой половины. Самый короткий акт и самый важный.

**Задача акта: дать надежду такой силы, чтобы пятый акт её отравил.**

---

# ЧАСТЬ 1 — ТИМ (~40 мин)

♪ `Слышно` — тема Депо, но с одной чужой нотой, которая приходит с запада
и не вписывается в тональность. Слушатель чувствует раздражение и не понимает почему.

## 1.1 Стук стал регулярным

С запада теперь стучит **каждый день**. Ритмично. Приближается.

Город раскалывается на реакции — это лучший материал для флейвора акта:

| Кто | Что говорит |
|---|---|
| Путейские | «Работают. Кто-то работает!» — счастье, слёзы, все на перроне |
| Башня | «Несанкционированные работы. Установить производителя» |
| [[Тупик]] | «Ну и что. Мы это уже слышали» (не слышали) |
| Зайцы | «Это подстава. Нас выманивают» |
| [[Зоя Буфетовна]] | молчит. Впервые за акт вообще ничего не говорит |

## 1.2 Тим догадывается

Никто в городе не связывает стук с братом Тима, потому что никто не верит,
что у Тима есть брат: [[Расписание]] сказало `НЕ ЗАРЕГИСТРИРОВАН`.

Тим связывает.

```
ТИМ:    Это он.
СВЕТА:  Кто?
ТИМ:    Яр. Мой брат.
СВЕТА:  (жёлтый) Тим...
ТИМ:    Он всегда так. Ему если что-то надо — он просто берёт и делает.
ТИМ:    Он один раз холодильник чинил. Три дня. Он его починил.
СВЕТА:  Тим, там сто лет никого...
ТИМ:    Он чинил холодильник ТРИ ДНЯ, Свет.
```

**Он прав.** И он единственный, кто прав. И ему никто не верит.

## 1.3 [[Багажное отделение]] и [[Контролёр]]

Тим хочет забраться повыше, чтобы свистнуть дальше. Самая высокая точка —
крыша Багажного.

[[Зоя Буфетовна]] **запрещает**: «Туда не ходи. Там проверяют.»
Не объясняет.

Тим идёт.

### [[Босс — Контролёр]], фаза 1

Первая встреча. Полный разбор — [[Контролёр]], [[Босс — Контролёр]].

Бой, который нельзя выиграть. 90 секунд. Задача — уклоняться от компостера,
пока идёт проверка документов. Каждое попадание = настоящий прокол.

Разговор во время боя — обычная процедура:

```
КОНТРОЛЁР:  Ваш билет.
        [Тим уворачивается]
КОНТРОЛЁР:  Не бегите. Я не тороплюсь.
КОНТРОЛЁР:  Тариф детский.
КОНТРОЛЁР:  Пункт отправления — не указан в системе.
КОНТРОЛЁР:  Пункт назначения — заполнен от руки.
КОНТРОЛЁР:  Это нарушение, но незначительное.
        [щелчок]
КОНТРОЛЁР:  Сопровождающий?
ТИМ:        Что?
КОНТРОЛЁР:  Детский билет действителен при сопровождающем.
КОНТРОЛЁР:  Где ваш сопровождающий?
ТИМ:        Он... он на западе. Он идёт.
КОНТРОЛЁР:  (пауза)
КОНТРОЛЁР:  Понятно.
```

Финал сцены: он **не ссаживает**. Он предупреждает.
И уходит, и на прощание — единственная почти человеческая реплика за игру:

```
КОНТРОЛЁР:  Найдите взрослого.
КОНТРОЛЁР:  Пожалуйста.
```

## 1.4 Крыша

Тим забирается наверх. Один. Ночь.
Внизу — весь город. На западе — темнота.

Он свистит `··`.

Ждёт.

Ждёт.

Ждёт. Игра не торопит. Кнопки не работают.
**Сорок секунд.**

▶ **ПЕРЕКЛЮЧЕНИЕ #7** — прямо посреди ожидания.

# ЧАСТЬ 2 — ЯР (~40 мин)

♪ `Мираж` — тема Насыпи, дрожащая, с наложенным эхом самой себя.

## 2.1 Стройка

Путь идёт. Счётчик растёт. Бригада работает. [[Проводник]] считает вслух,
и Яр считает вместе с ним, и уже непонятно, кто начал.

**Здесь игрок должен быть счастлив.** Работа идёт, есть команда, есть цель.
Лучший геймплейный отрезок Насыпи: 15 минут ритмической стройки с
[[Костыли]] и №17, который ходит хвостом.

## 2.2 №17

Ночью, у костра. Все спят. №17 не спит.

```
    №17:  ··
```

Свисток. Тихий. Без причины.

> **выбор:** свистнуть в ответ / не свистеть

Если игрок свистит `··` — №17 садится ближе и остаётся рядом до конца игры.
Если нет — уходит и больше не подойдёт **никогда**.

Игра не отмечает это никак. Ни звука, ни ачивки.
**Это второе условие [[Концовка — Два гудка]].**

## 2.3 [[Мираж-станция]]

Днём, в жару, на горизонте — **вокзал**. Огромный, светлый, живой.
Люди на перроне. Поезд у платформы. Гудки.

И на перроне стоит **Тим**.

Он машет.

```
ЯР:         (бежит)
ЯР:         ТИМ!
ПРОВОДНИК:  Стой.
ЯР:         ТИМ!!
ПРОВОДНИК:  Ярослав. Стой.
```

### [[Босс — Мираж-станция]]

Психологический бой. Механика: **не двигаться**.

Мираж атакует не уроном — он атакует **правдоподобием**. Тим на перроне
говорит правильные вещи. Голосом Тима. Тим зовёт. Тим плачет. Тим спрашивает,
почему брат не идёт.

Ходы Яра: `ИДТИ` / `СТОЯТЬ` / `СЛУШАТЬ` / `НЕ ВЕРИТЬ`

Каждый ход `ИДТИ` — мираж отодвигается и забирает воду (реально, из фляги).
Каждый `СТОЯТЬ` — мираж говорит что-то более точное, более настоящее.

На пятом ходу мираж говорит фразу, которую **знают только они двое** —
что-то из детства, что игра ни разу не показывала.

Игрок в этот момент сам почти верит.

Победа = `НЕ ВЕРИТЬ` на шестом ходу, когда воды осталось меньше половины.

Мираж гаснет. Пустой песок.

```
ЯР:         (на коленях)
ЯР:         Откуда он знал про качели.
ПРОВОДНИК:  Ты знал.
ЯР:         ...
ПРОВОДНИК:  Он взял у тебя.
        [пауза]
ЯР:         А ты откуда знаешь, что я знал?
ПРОВОДНИК:  (не отвечает)
ПРОВОДНИК:  Пойдём. Воды мало.
```

**Первый раз, когда Яр задал прямой вопрос.** И первый раз, когда не получил ответа.
Игрок должен это заметить. Яр — нет.

## 2.4 Гудок

Ночь. Костёр. Яр не спит.
И тогда — с востока, издалека, через триста километров —

```
    ··
```

Яр садится. Медленно.

```
ЯР:     ...
ЯР:     (встаёт)
ЯР:     Это...
```

▶ **ПЕРЕКЛЮЧЕНИЕ #8**

# ЧАСТЬ 3 — ОБА (~20 мин)

**Единственная сцена в игре до акта VI, где экран разделён.**
Слева Яр на Насыпи. Справа Тим на крыше. Между ними — триста километров.

♪ `··` — трек из двух нот. Больше в нём ничего нет.

## 3.1

```
[СЛЕВА]                          [СПРАВА]

ЯР стоит.                        ТИМ сидит на краю крыши,
Смотрит на восток.               обхватив колени. Он уже
                                 не ждёт. Он просто сидит.
```

**Игрок управляет Яром.** Свисток. [R].

```
ЯР:     ··
```

Пауза. Долгая. Звук уезжает.

```
                                 [ТИМ поднимает голову]
```

Пауза.

```
                                 ТИМ:  ...
                                 ТИМ:  ··
```

Пауза.

```
ЯР:     ··
                                 ТИМ:  ··
ЯР:     ··
                                 ТИМ:  ··
ЯР:     ··          ТИМ:  ··
        ··                ··
        ··                ··
```

**Управление отдаётся обоим одновременно.** Игрок жмёт [R] и оба свистят.
Быстрее. Ещё быстрее. Экран заполняется сигналами.
Оба смеются. Оба плачут. Ни одного слова.

Полторы минуты. Никакого текста.

Это **лучшая сцена игры**, и в ней нет ни одной реплики.

## 3.2 Что означает `··`

После — короткий флешбэк. Единственный в игре.
Пиксельная квартира. Коридор. Ночь. Закрытая дверь спальни.

Два мальчика по разные стороны стены. Нельзя шуметь.

```
        [стук в стену: · ·]
        [стук в ответ: · ·]
```

И всё. Три секунды. Возвращаемся.

Игрок теперь понимает [[Свистковая азбука|азбуку]] по-настоящему.

## 3.3 Оба решают

Разделённый экран. Оба говорят вслух, одновременно, разное:

```
ЯР:                              ТИМ:
Он там.                          Он идёт.
Я дойду.                         Он правда идёт.
Я его заберу.                    Надо, чтобы ему было куда прийти.
Мы поедем домой.                 Надо, чтобы тут всё было хорошо.
```

Слушая по отдельности — оба правы.
Слушая вместе — **они уже спорят**, не зная об этом.

## 3.4 Щелчок

Экран сводится в один. Оба гаснут.

В темноте:

```
    [щелчок компостера]
```
