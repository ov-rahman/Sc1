# Ночной обход

**Роглайт-режим внутри игры.** Наследует The Binding of Isaac и Enter the Gungeon.
Диегетически — сны [[Яр]]а. Механически — источник апгрейдов.
Сюжетно — сто маленьких историй тех, кто не доехал.

---

## Что это

[[Погребённый состав]] — целый поезд, засыпанный песком. Один из шести,
что попали на Перегон за сто лет ([[Перегон (мир)#Как сюда попадают]]).

Яр находит его в акте III. Внутрь можно спуститься через люк (нужен **лом**).

Внутри — вагоны. Много. Больше, чем может быть в одном составе.
Каждый раз — другие.

```
    ┌───┬───┬───┬───┬───┬───┐
    │ ▣ │ ▢ │ ▢ │ ✦ │ ▢ │ ⊙ │
    └───┴───┴───┴───┴───┴───┘
      ↑                    ↑
    вход              локомотив

    ▣ вход    ▢ вагон    ✦ багажный    ⊙ босс
```

---

## Забег

**8–14 вагонов**, от входа к локомотиву. Линейно, с развилками
(2–3 ветки, выбираешь на стыке).

| Тип вагона | Что внутри |
|---|---|
| **Плацкартный** | 3–5 волн уклонения, обычные противники |
| **Купейный** | закрытые двери. Выбираешь одну из трёх |
| **Багажный** ✦ | предмет + чужая история |
| **Ресторан** | вода, отдых, торговец ([[Пломба]] во сне) |
| **Почтовый** | письмо. Читается. Лор |
| **Тамбур** | развилка |
| **Локомотив** ⊙ | босс забега |

Длительность — 12–20 минут.

---

## Правила

1. **Урон переносится в реальность.** Проколы на билете — настоящие.
   Это не сон в смысле «без последствий».
2. **Предметы переносятся.** Всё, что вынес, — твоё.
3. **Отцеп внутри = проснуться.** Теряешь всё, что нашёл в этом забеге.
   Мёртвых проколов ⊗ не даёт (это не бой с боссом сюжета).
4. **Вода не тратится.** Внутри Яр спит.
5. **Заходить можно сколько угодно**, начиная с акта III.

## Предметы (40+)

Ломающие правила, как положено в жанре. Все — **чужие вещи**.

| Предмет | Эффект | Чей был |
|---|---|---|
| **Термос** | +0.3 л к ёмкости навсегда | геолога |
| **Очки** | видно скрытые снаряды | бухгалтера |
| **Гармошка** | ход `ИГРАТЬ` — снимает терпение всем сразу | солдата |
| **Детские варежки** | −1 урон от всего, **всегда** | ребёнка |
| **Часы без стрелок** | замедляют фазу уклонения на 15% | никого не помнят |
| **Обручальное кольцо** | ×2 к ◻ от вписанных | двоих |
| **Пачка писем** | лор. **Не даёт ничего** | всех |
| **Компостер (старый)** | вычёркивание доступно у Яра без [[Проводник]]а | ??? |
| **Фотография** | при отцепе один раз не теряешь предметы | семьи |
| **Ключ от квартиры** | ничего. Совсем ничего | **точно такой же, как у [[Тим]]а** |

Последний предмет — не сюжетный. Он просто есть. Игрок сам решит,
что это значит.

## Истории

Каждый багажный вагон — **чужой чемодан и микро-история**.
Три-четыре предложения на экране, без озвучки, без музыки.

```
    Чемодан №44.

    Внутри — свадебное платье, зашитое в простыню,
    и записка: «не открывай до вокзала».

    Он открыл.
```

```
    Чемодан №112.

    Инструменты. Хорошие, дорогие, каждый в своём гнезде.
    Одного не хватает.

    Он его кому-то одолжил.
```

**Всего 60 таких историй.** Ни одна не связана с сюжетом.
Ни одна не имеет продолжения.

Это те, кто не доехал. Их не спасти, их не вписать, их даже не встретить.
Единственное, что можно, — **прочитать**.

## Боссы забега

Три, выпадают случайно:

| Босс | Что |
|---|---|
| **Локомотив (спящий)** | капхедовский, 3 фазы, шатуны и пар |
| **Начальник поезда** | не дерётся. Проверяет билет. Как [[Контролёр]], но во сне, и его **можно** переспорить |
| **Сам Яр** | зеркальный бой. Он повторяет твои ходы с задержкой в один. Единственный способ — **ничего не делать три хода** |

Последний открывается только с 5-го забега и появляется редко.
После победы Яр просыпается с одной репликой:

```
ЯР:     ...ладно. Так.
```

---

## Зачем это в игре

1. **Разгружает.** Маршрут Яра тяжёлый и одинокий; забег — азартный
   и быстрый.
2. **Даёт прогрессию** там, где сюжет её не даёт.
3. **Рассказывает историю мира вширь**, не занимая ни минуты основного сюжета.
4. **Удовлетворяет референсы** Isaac/Gungeon, не ломая тон.

---

## Чего мы НЕ делаем

- ❌ Не делаем режим обязательным. Всю игру можно пройти, ни разу не спустившись.
- ❌ Не даём там сюжетных откровений. Ничего критичного.
- ❌ Не делаем мета-прогрессию с валютой и деревьями. Нашёл — унёс. Всё.
- ❌ Не даём его [[Тим]]у. Это сон Яра, и Тиму в пустыне делать нечего.
