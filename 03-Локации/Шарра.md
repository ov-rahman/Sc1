# ШАРРА

**Пустыня. Акт I целиком. Восемь дней. Ни одного живого существа.**

---

## Задача локации

Сделать так, чтобы к концу акта игрок **хотел встретить кого угодно**.

Потому что в акте III он встретит [[Мимми]].

---

## Как выглядит

Не барханы и не красивая пустыня. **Плоское**.

Растрескавшаяся глина, местами песок, местами соль.
Ни одного возвышения. Горизонт ровный на все триста шестьдесят.

**3–6 объектов в кадре.** Не больше. Никогда.

| Что бывает в кадре | |
|---|---|
| Камень | |
| Куст. Сухой. Один | |
| Кость. Крупная. Не понять чья | |
| Следы | всегда старые |
| Далёкая точка на горизонте | это [[Шарги\|шарг]]. Он не приближается |

Палитра: выбеленное небо `#EAE3D2`, белёсая глина `#D9C9A8`,
**фиолетовые тени** `#4A3C5A`. Ни одной чёрной линии.

♪ `Шарра` — ветер и одна нота. Мелодии нет.
Мелодия появится в акте II и это будет заметно.

---

## Что делает игрок

Идёт. Выживает. Считает.

| Механика | Как учится |
|---|---|
| **Вода** | фляга из поезда, 0.7 л. Не пополняется сама |
| **Жар** | тень от камня. Тень бывает три раза за акт |
| **Ночь** | холодно. Костёр из сухого куста |
| **Счёт** | [[Дали]] считает дни вслух. Если долго молчать — **сбивается** |
| **Направление** | по следам. Все ведут на восток |

**Ни одного боя за весь акт.**

## Пять находок

Всё, что происходит в акте I, — это пять предметов.
Каждый — отдельная маленькая сцена.

### 1 · Следы (день 1)

Много. Разных. Все старые. Все идут на восток.

```
ДАЛИ:   Ходили.
ДАЛИ:   (пауза)
ДАЛИ:   Ходили — значит, есть куда.
```

### 2 · Кости, сложенные в кучку (день 2)

Аккуратно. Не свалены — **сложены**. Кто-то тратил время.

```
ДАЛИ:   Их кто-то складывал.
ДАЛИ:   Зачем складывать кости?
        [пауза]
ДАЛИ:   Ладно. Так.
```

Первое «Ладно. Так.» из восьми.

### 3 · Надпись (день 4)

Выцарапана камнем на плоском валуне. Крупно. Криво.

```
        НЕ ОТВЕЧАЙ
```

**Первый совет, который он получает в этом мире.**
Дал его тот, кого уже нет.

Он его не послушает.

### 4 · Голос (день 6)

**Ключевая находка акта.**

В трещине лежит **узелок** — маленький, влажный, размером с кулак.
Он **дышит**.

Игрок может подойти. Может уйти. Может стоять.

Если взять — узелок **тихо мычит**. Не слова. Просто звук
чьего-то горла.

```
ДАЛИ:   ...
ДАЛИ:   (кладёт обратно)
ДАЛИ:   (отходит)
        [пауза]
ДАЛИ:   (возвращается и берёт)
```

Он несёт его всю игру. Это **первый предмет-часть**,
который видит игрок, и **никто не объясняет, что это**.

Объяснит [[Джаббер]] через два часа, на другом маршруте,
в комической сцене. И игрок поймёт задним числом,
что Дали шесть дней таскал в кармане чей-то голос.

### 5 · Точка на горизонте (дни 3, 5, 7)

Далеко. Не двигается. Появляется трижды, каждый раз ближе
**на чуть-чуть**.

Дали идёт к ней дважды. Она не приближается.
На третий раз он перестаёт обращать внимание.

**Это [[Шарги|шарг]].** Он идёт за ним с первого дня.
Он догонит в [[Акт VI — Солёный город]].

## Ночь

Каждую ночь — костёр и **счёт вслух**.

Это единственные реплики [[Дали]] за весь акт,
и их пишет сценарист **как монолог одинокого подростка**,
а не как экспозицию.

```
ДАЛИ:   День шесть. Воды двести.
ДАЛИ:   По пятьдесят — четыре дня.
ДАЛИ:   За четыре дня куда-нибудь.
        [пауза]
ДАЛИ:   Тимка бы ныл.
        [пауза]
ДАЛИ:   ...Ови. Ови бы ныл.
        [пауза]
ДАЛИ:   Он не Тимка.
        [пауза]
ДАЛИ:   Я устал.
```

*(«Тимка» — оговорка. Так звали кого-то, о ком игра
не расскажет никогда. Одна реплика. Больше нигде.)*

Он **один раз шутит** — на восьмой день, и это единственная
шутка на маршруте до потери смеха:

```
ДАЛИ:   Ну хоть очередей нет.
        [пауза]
ДАЛИ:   ...это было смешно.
        [пауза]
ДАЛИ:   Мне было смешно.
```

## Конец акта

День восемь. На горизонте — **блеск**.

Не мираж. Что-то стеклянное, много, до горизонта.

[[Стеклянный лес]].

```
ДАЛИ:   (долго смотрит)
ДАЛИ:   Ладно.
ДАЛИ:   Так.
```

## Правило

Этот акт **скучный по ощущению и не скучный по темпу**.
Разница — в пяти находках и в том, что каждая ночь короткая.

Если на плейтесте люди бросают в акте I — режем **дни**,
а не находки. Восемь дней можно сжать до шести.
Пять находок — нельзя тронуть ни одной.
