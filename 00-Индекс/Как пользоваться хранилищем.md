# Как пользоваться хранилищем

## Открытие

1. Obsidian → **Open folder as vault** → выбрать корень репозитория.
2. Включить **Graph view** — видно три кластера: Насыпь (охра), Депо (бирюза), сквозные (белый).
3. Открыть `Карта.canvas` — визуальная схема сюжета от пролога до концовок.

## Соглашения

### Фронтматтер

У каждой заметки есть YAML-шапка:

```yaml
---
tags: [персонаж, депо]
aliases: [Зоя, тётя Зоя]
маршрут: Тим
акт: [I, II, V]
статус: готово
---
```

- `маршрут` — `Яр` / `Тим` / `оба`
- `акт` — в каких актах встречается
- `статус` — `готово` / `черновик` / `нужно решить`

### Теги

| Тег | Значение |
|---|---|
| `#персонаж` | карточка действующего лица |
| `#локация` | место |
| `#босс` | бой с боссом |
| `#сцена` | написанный диалог |
| `#механика` | геймдизайн |
| `#лор` | устройство мира |
| `#концовка` | финал |
| `#нужно-решить` | открытый вопрос, требует решения продюсера |
| `#спойлер` | не показывать художникам на ранней стадии |

### Обозначения в тексте сцен

```
ТИМ:            реплика персонажа
ТИМ (тихо):     ремарка исполнения
[ДЕЙСТВИЕ]      то, что делает игра, а не персонаж
> выбор:        игрок выбирает
    ├ вариант А → ведёт в [[заметку]]
    └ вариант Б → ведёт в [[заметку]]
{ФЛАГ: имя}     сюжетный флаг ставится/проверяется
♪ трек          какая музыка играет
```

### Флаги

Все сюжетные флаги перечислены в [[Развилки и последствия]]. Формат: `{ФЛАГ: ЗОЯ_ЗНАЕТ}`.
Флаги, которые переживают перезапуск игры, помечены 🔒 — их всего четыре, и это важно.

## Порядок чтения для разных людей

**Продюсеру:** [[Питч]] → [[Три обещания игроку]] → [[Объём контента]] → [[Риски]] → [[Дорожная карта]]

**Сценаристу:** [[Темы и вопросы]] → [[Синопсис — полный]] → акты I–VII → [[Правила письма диалогов]] → сцены

**Геймдизайнеру:** [[Кор-луп]] → [[Бой — Тим]] → [[Бой — Яр]] → [[Ведомость (механика)]] → [[Кривая сложности]] → [[Список боссов]]

**Художнику:** [[Визуальный стиль]] → [[Палитры]] → [[Дизайн персонажей — гайд]] → локации → персонажи

**Композитору:** [[Тон, стиль, палитра]] → [[Саундтрек]] → [[Свистковая азбука]] → [[Звуковой дизайн]]

## Правило одного источника правды

Если два документа противоречат друг другу — прав тот, что ближе к [[Правило Незавершённости]].
Метафизика мира важнее удобства сцены. Если сцена требует нарушить закон мира —
переписывается сцена, а не закон.
