# С-44 · РАЗГОВОР С ФОНАРЩИКОМ

**[[Акт VI — Горловина]]. Четыре минуты. Ни одного слова.
Рассказывает всё.**

Доступна **только если игрок выучил все 16 сигналов**
[[Свистковая азбука|азбуки]].

♪ *(нет)* — только свистки и ветер

---

## Как открывается

Никак не отмечено.

[[Фонарщик]] появляется на [[Насыпь|насыпи]] в акте VI,
как появлялся во всех предыдущих. Обычно он свистит две-три реплики
и уходит.

Но если в блокноте игрока **все 16 сигналов** — при попытке
заговорить открывается **полный диалог**: свистковое меню
разворачивается в 16 позиций вместо обычных четырёх.

---

## Как это выглядит

Игрок выбирает сигнал. Фонарщик отвечает сигналом.
**Субтитров нет** — только значки.

```
        ЯР:         ··—··
        ФОНАРЩИК:   ·
```

Игрок, который выучил язык, читает это как разговор.
Игрок, который не выучил, сюда не попадёт.

**Опция «Показывать разбор свистков» здесь принудительно
отключена.** Единственное место в игре, где настройка
доступности игнорируется — и это обсуждалось,
и решение принято сознательно: сцена **является** наградой
за знание, и субтитры её уничтожают.

*(Компромисс: после первого прохождения сцены субтитры
становятся доступны при повторе. Первый раз — без.)*

---

## Разговор (расшифровка для сценаристов)

Игрок может спросить в любом порядке. Здесь — полный набор.

```
ЯР:        ··              «я здесь, ты где?»
ФОНАРЩИК:  ··              «я здесь»
```

```
ЯР:        ··—··           «я тебя вижу»
ФОНАРЩИК:  ·               «да»
           ~~              «мне плохо»
```

*Он видит, что Яр его видит. И ему от этого плохо,
потому что сам он слеп.*

```
ЯР:        —               «внимание, я говорю»
           ···             «стой»
           ——              «отправление»
           —~—             «врёшь»
```

*Яр спрашивает: «то отправление, которого все ждут, —
это ложь?»*

```
ФОНАРЩИК:  ·               «да»
           ·—              *(пауза)*
           ——              «отправление»
           ·               «да»
```

*«Да, ложь. И да, отправление.» Оба верны.*

```
ЯР:        —               «я говорю»
           ·—·—·—          «поехали»
           —··—            «дай воды»
```

*«Чтобы поехать — нужно что-то дать.» Яр формулирует
[[Линия#Ступень 3|цену Линии]] сам, свистками,
не зная, что прав.*

```
ФОНАРЩИК:  ·
           ·
           ·
```

*Трижды «да». Единственный раз, когда он повторяет.*

## Про [[Проводник]]а

```
ЯР:        —·              «не ходи сюда»
           —               «я говорю»
           ··—··           «я тебя вижу»
```

*«Тот, кто идёт со мной, — ты его видишь?»*

```
ФОНАРЩИК:  ·               «да»
           ~~              «мне плохо»
```

**Он его видит.** Слепой видит.

```
ЯР:        ——              «отправление»
           ··              «ты где?»
```

*«Он машинист?»*

```
ФОНАРЩИК:  (долгая пауза)
ФОНАРЩИК:  ~               *(один дрожащий — «не уверен»)*
```

**Единственный раз за игру, когда Фонарщик не уверен.**

И потом:

```
ФОНАРЩИК:  ——              «отправление»
           ···             «стой»
           ·—              «иду к тебе»
```

*«Тот, кого я жду, остановился и идёт пешком.»*

Это про настоящего [[Машинист]]а, который сто лет назад
сошёл с локомотива и пошёл вдоль насыпи.

Фонарщик ждёт **его**. И видит на [[Проводник]]е его форму.

```
ФОНАРЩИК:  —               «я говорю»
           ··              «я здесь»
        [пауза]
ФОНАРЩИК:  ··
        [пауза]
ФОНАРЩИК:  ··
```

*«Передай ему: я всё ещё жду.»*

## Про себя

```
ЯР:        ··              «ты кто?»
ФОНАРЩИК:  (не отвечает)
ЯР:        ··
ФОНАРЩИК:  (не отвечает)
ЯР:        ··
ФОНАРЩИК:  (свистит что-то, чего нет в азбуке)
```

**Сигнал, которого нет в блокноте.** Он не добавляется.
Его нельзя повторить. Игрок услышал его один раз.

Это единственный ответ на вопрос «кто такой [[Фонарщик]]».
Его не расшифровать.

*(В файлах игры этот сигнал называется `unknown_17.wav`.
Он не соответствует ни одной букве, ни одному коду,
ни одному ключу. Он просто есть.)*

## Финал

```
ЯР:        ·               «да»
ФОНАРЩИК:  ·               «да»
        [Фонарщик уходит]
        [фонарь удаляется]
        [Яр стоит]
```

```
ЯР:     (вслух, впервые за сцену)
ЯР:     ...ага.
```

**Единственное произнесённое слово за четыре минуты.**

---

## Что игрок узнаёт

Всё. Полный лор [[Линия|Линии]], природу [[Проводник]]а,
цену рельсов, кто такой [[Машинист]].

**Свистками.** Без единого слова.

Это самая элегантная система награды в документе,
и она стоит нам шестнадцати звуковых файлов.

---

## Правило

Если на плейтесте выяснится, что до сцены доходит менее 5% игроков —
**не упрощать доступ**. Это правильный процент.

Сцена существует, чтобы её нашли те, кто учил язык.
Остальные узнают то же самое словами — от [[Контролёр]]а
на [[Станция|Станции]], в акте VII, коротко и без красоты.
