# С-22 · ПЕРВОЕ ИМЯ

**[[Акт III — Вера]]. Центральная сцена маршрута [[Тим]]а. ~7 минут.**

♪ `Зал ожидания` (орган) → **тишина** → щелчки сплит-флапа

---

## 22.1 Просьба

```
        [Первый путь. Тим ест. Обычный день.]
        [подходит ПЕСОЧНИЦА. Дёргает за куртку.]
        [она по пояс ему. Из щелей сыплется песок.]

ПЕСОЧНИЦА:  Впиши меня.
ТИМ:        Куда?
ПЕСОЧНИЦА:  В книжку. Ну, в большую. Которая на подставке.
ТИМ:        Мне туда нельзя, наверное.
ПЕСОЧНИЦА:  Тебе можно. Ты же едешь.
ТИМ:        ...откуда ты знаешь?
ПЕСОЧНИЦА:  От тебя пахнет улицей.
        [пауза]
ТИМ:        Тут нет улицы.
ПЕСОЧНИЦА:  Ага.
```

```
ТИМ:        А зачем тебе?
ПЕСОЧНИЦА:  (пожимает плечами)
ПЕСОЧНИЦА:  Мне сто лет.
ТИМ:        Чего?
ПЕСОЧНИЦА:  Сто. Я считала.
ПЕСОЧНИЦА:  Я всё уже умею. Я умею читать, и завязывать,
            и считать до тыщи.
ПЕСОЧНИЦА:  Почему я всё ещё маленькая?
        [пауза]
ТИМ:        Я не знаю.
ПЕСОЧНИЦА:  Вот. И я не знаю.
ПЕСОЧНИЦА:  Впиши меня, а?
```

> **выбор:**
> ├ «Ладно.» → идут вместе
> ├ «Мне надо спросить у тёти Зои.» → **Зоя запрещает**. Тим идёт всё равно, ночью
> └ «Не могу.» → она уходит. Сцена повторится через игровой день. И ещё раз. И ещё

Третий вариант можно жать бесконечно. Она будет приходить.
Она приходила сто лет ко всем.

## 22.2 Зал ожидания

```
        [орган. Столбы света. Пыль.]
        [аналой посреди зала. Тетрадь.]
        [никого. Кроме двоих на скамейках, которые не поворачиваются.]

ПЕСОЧНИЦА:  Вон она.
ТИМ:        Большая.
ПЕСОЧНИЦА:  Ага.
ТИМ:        (подходит)
        [подсказка: (A) ОТКРЫТЬ]
```

```
        [открывает]
        [страница. Разлинована. Сто восемьдесят семь строк.]
        [все пустые]

ТИМ:        ...тут никого нет.
ПЕСОЧНИЦА:  Ага.
ТИМ:        Совсем никого.
ПЕСОЧНИЦА:  Ну да. Себя же нельзя.
ТИМ:        Почему нельзя?
ПЕСОЧНИЦА:  Так правило.
        [пауза]
ПЕСОЧНИЦА:  Тебя должен кто-то другой.
        [пауза]
ПЕСОЧНИЦА:  А другому тоже надо ехать.
        [пауза]
ПЕСОЧНИЦА:  А никто не едет.
```

**Тим не понимает. Игрок понимает.**

Весь замок мира объяснён семилетним ребёнком за четыре реплики.

---

## 22.3 Запись

```
        [появляется перо]

    [впиши имя]

    ____________
```

**Игрок печатает вручную.** Буква за буквой.
На геймпаде — колесом, по одной.

Это медленно. Это нарочно медленно.

`П-Е-С-О-Ч-Н-И-Ц-А`

```
        [подтверждение]
        [перо касается бумаги]
        [ничего не происходит]
```

**Ничего.**

Ни вспышки, ни звука, ни музыки. Орган продолжает играть.

```
ТИМ:        ...
ТИМ:        Всё?
ПЕСОЧНИЦА:  Не знаю.
ТИМ:        Ты чувствуешь чего-нибудь?
ПЕСОЧНИЦА:  Не-а.
ТИМ:        Ну извини.
ПЕСОЧНИЦА:  Ничего.
```

**Тим разворачивается уходить.**

## 22.4 Зевок

```
        [щелчок]

        [ТАБЛО. Одна строка. Медленно, буква за буквой.]

   ОТПРАВЛЕНИЕ            ПУТЬ    ВРЕМЯ
 ▸ ПЕСОЧНИЦА               1     — : —

        [Тим оборачивается]

        [пауза]

   ▸ СПАСИБО

        [строка перещёлкивается обратно через две секунды]
        [никто, кроме Тима, не видел]
```

```
ПЕСОЧНИЦА:  Ой.
ТИМ:        Что?
ПЕСОЧНИЦА:  Ой, что это.
ПЕСОЧНИЦА:  Мне... я, кажется, спать хочу?
ТИМ:        Чего?
ПЕСОЧНИЦА:  (садится на пол)
ПЕСОЧНИЦА:  Я никогда не хотела спать.
```

```
        [она засыпает]
        [прямо там, на кафеле, посреди Зала ожидания]
        [песок из неё перестаёт сыпаться]
```

## 22.5 Город

```
        [первым входит один. Останавливается.]
        [потом ещё двое.]
        [потом десять.]
        [потом весь зал.]

        [никто ничего не говорит]
        [сорок секунд]
```

**Сорок секунд без единой реплики.** Полный зал существ стоит кругом
и смотрит на спящего ребёнка.

Кто-то садится на скамью. Кто-то на пол.
Кто-то держится за спинку.

```
        [входит ЗОЯ]
        [видит]
        [закрывает рот рукой]
        [выходит]
```

Она **не радуется**. Игрок не понимает почему.

```
        [все смотрят на Тима]
        [не с угрозой. С надеждой.]

        [счётчик в углу экрана меняется:]

    ВНИМАНИЕ  ██████████  100
```

## Правило

и сел на пол.
