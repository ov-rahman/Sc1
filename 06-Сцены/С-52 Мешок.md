# С-52 · МЕШОК

**[[Акт VII — Станция]]. Правда о том, чем оплачена дорога. ~12 минут.**

♪ *(тишина)* — с первой секунды и до конца сцены.
Ни одного звука, кроме ветра и бумаги.

---

## Ситуация

Ночь перед прибытием. [[Насыпь]]. Костёр.

[[Проводник]] **спит**.

Он не спал ни разу за пять актов. Это первый раз.
Игрок должен насторожиться.

Мешок лежит рядом. Тот самый, что висел у него за плечом всю игру.

---

## 52.1 Выбор

**Игра не подталкивает.** Никакой подсветки, никакой подсказки,
никакого маркера.

Можно лечь спать и пойти дальше утром.
Тогда сцены не будет вообще, и [[Босс — Проводник]] случится
без этого знания, и правда откроется только на [[Станция|Станции]],
из уст [[Контролёр]]а, коротко и вскользь.

Мы **разрешаем игроку не узнать**.

## 52.2 Если открывает

```
        [Яр развязывает горловину]
        [заглядывает]
        [бумажки. Много.]

        [ветер]
        [мешок опрокидывается]
        [бумажки летят по всей насыпи]
```

**Интерактивный отрезок. Пять минут.**

Игрок бегает по тёмной насыпи и **ловит бумажки**.
Их сотни. Собрать все нельзя — ветер уносит.

Игра засчитывает **любое количество**.

На каждой пойманной — одно слово, разными почерками:

```
    да
```
```
    да
```
```
    согласен
```
```
    да
```
```
    ладно
```
```
    да, только быстрее
```
```
    да
```
```
    хорошо
```
```
    да
```

Некоторые написаны криво. Некоторые — печатными буквами.
Некоторые — не буквами вообще, а **насечками**, как у [[Костыли]].

Одна — детским почерком.

## 52.3

```
        [Проводник стоит и смотрит, как он их собирает]
        [он не спал]

ЯР:         Что это.
ПРОВОДНИК:  Согласия.
ЯР:         Чьи?
ПРОВОДНИК:  Тех, кто тут был.
ЯР:         ...Костылей?
ПРОВОДНИК:  Тоже.
```

```
ЯР:         Согласия на что?
ПРОВОДНИК:  (пауза)
ПРОВОДНИК:  Рельс не кладётся в землю, Ярослав.
ПРОВОДНИК:  Рельс кладётся в чьё-то согласие закончиться.
ПРОВОДНИК:  Каждый метр — один «да».
```

**Пауза. Долгая.**

```
ЯР:         Сколько я положил.
ПРОВОДНИК:  Ты знаешь. У тебя счётчик.
```

И камера **опускается к углу экрана**, где всю игру стояло:

```
    ЗАБИТО КОСТЫЛЕЙ:  1 847
```

*(число игрока)*

Оно висело там пять актов. Игрок гордился, что оно растёт.

## 52.5 Двенадцать

```
ПРОВОДНИК:  Хочешь посмотреть?
ЯР:         На что.
ПРОВОДНИК:  На тех, кто не дождался.
```

**Опционально.** Игрок может отказаться.

Если соглашается — открывается путь назад, по своим рельсам.
**Десять минут ходьбы.** Двенадцать точек, отмеченных на карте
маленькими крестиками, которых раньше не было.

Каждая — место, мимо которого Яр проходил все шесть актов
и не смотрел.

В каждой — **сухая оболочка**. Костыль, свернувшийся,
как обгоревшая спичка. С номерком.

```
    №4
    №9
    №22
    №31
    №33
    №38
    №40
    №44
    №51
    №55
    №58
    №59
```

Двенадцать номеров, которых не было в бригаде,
когда игрок считал их в [[Стойбище Костылей]].

**Если игрок тогда пересчитал — он это заметил.**
Игра ничего не сказала.

Возле каждого можно постоять. Ничего не происходит.
Ни реплики, ни музыки, ни отметки.

## 52.6 №17

Если игрок **ответил №17** в [[Акт IV — Гудок]] —
он идёт с Яром всю дорогу.

У последней, двенадцатой оболочки:

```
    №17:  ~~        («мне плохо»)
    ЯР:   Мне тоже.
    №17:  ··        («я здесь»)
```

> **выбор:** свистнуть в ответ / нет

```
    ЯР:   ··
```

И №17 **садится рядом**. И они сидят у чужой оболочки
до рассвета.

Это последняя тихая сцена маршрута Яра.

## 52.7 Утро

```
        [рассвет]
        [Яр стоит]
        [бумажки в руках. Штук сорок. Остальные унесло.]

ЯР:     ...
ЯР:     (кладёт их обратно в мешок)
ЯР:     (аккуратно)
ЯР:     (завязывает)
        [пауза]
ЯР:     Ладно.
ЯР:     Так.
```

**Седьмой раз за игру.**

Он вешает мешок себе на плечо.

И идёт к [[Горловина|Горловине]].

---

## Что это меняет

Ничего механически. Ни одного бонуса, ни одного предмета,
ни одной разблокировки.

Меняется только то, **как игрок смотрит на счётчик**
последние два часа игры.
