# С-13 · ОСТАНОВОЧНЫЙ ПУНКТ «НИЧЕГО»

**[[Акт II — Кто здесь]]. Единственная комедия на [[Насыпь|Насыпи]].
~6 минут.**

Задача: **рассмешить**. Обязательно. Если на плейтесте не смеются —
переписываем.

Потому что через три акта эта же сцена станет невыносимой.

♪ `Пункт` — маленький бодрый марш на расстроенной гармошке.
Играет только здесь. Никогда больше.

---

## До этого

Восемнадцать дней. Воды 0.9 л. [[Яр]] не разговаривал с живым существом
словами **ни разу за игру** ([[Костыли]] не говорят).

```
        [Яр идёт вдоль вешек]
        [впереди — что-то на горизонте]
        [подходит]

        [СТОЛБ. Один. С табличкой:]

        ╔══════════════╗
        ║   НИЧЕГО     ║
        ║   0 км       ║
        ╚══════════════╝

        [рядом — скамейка на двоих. Кривая. Самодельная.]
        [урна]
        [фанерное расписание, нарисованное от руки. Все графы пустые.]

        [и существо, которое ПОДМЕТАЕТ ПЕСОК]
        [веником]
        [в пустыне]
```

```
НАЧАЛЬНИК:  Здравствуйте. Вы на посадку?
ЯР:         ...что?
НАЧАЛЬНИК:  Остановочный пункт «Ничего».
НАЧАЛЬНИК:  Начальник пункта — я.
НАЧАЛЬНИК:  Ближайшее отправление — по расписанию.
ЯР:         У вас расписание пустое.
НАЧАЛЬНИК:  (пауза)
НАЧАЛЬНИК:  Совершенно верно.
НАЧАЛЬНИК:  Значит, скоро.
```

**Смех.** Обязательно здесь.

## 13.2 Разговор

Свободный диалог, ~15 тем. Игрок может спрашивать что угодно.
Начальник отвечает **абсолютно серьёзно** на всё.

```
ЯР:         Вы тут один?
НАЧАЛЬНИК:  Штат пункта — одна единица. Укомплектован полностью.
```

```
ЯР:         А пассажиры бывают?
НАЧАЛЬНИК:  Вы первый.
ЯР:         За сколько?
НАЧАЛЬНИК:  (пауза)
НАЧАЛЬНИК:  Вы первый.
```

```
ЯР:         Зачем скамейка на двоих?
НАЧАЛЬНИК:  Пассажиры бывают парами.
ЯР:         ...а если один?
НАЧАЛЬНИК:  Тогда сядет с краю. Так удобнее.
```

```
ЯР:         Зачем урна?
НАЧАЛЬНИК:  На пункте должна быть урна.
```

```
ЯР:         Зачем вы подметаете песок?
НАЧАЛЬНИК:  Пункт должен быть чистым.
ЯР:         Тут песок кругом.
НАЧАЛЬНИК:  Кругом — не моя зона обслуживания.
НАЧАЛЬНИК:  Моя — вот отсюда досюда.
        [показывает. Три метра на четыре.]
```

**И вот здесь игрок смеётся второй раз и что-то чувствует.**

## 13.3 Зарубки

```
        [на столбе — зарубки. Много. Очень много.]
        [они идут вокруг столба по спирали, сверху донизу, и ещё раз]

ЯР:         Это что?
НАЧАЛЬНИК:  Учёт.
ЯР:         Чего учёт?
НАЧАЛЬНИК:  Смен.
```

> **выбор:**
> ├ «Сколько их?» → см. ниже
> └ [не спрашивать] → он не скажет сам

```
ЯР:         Сколько их?
НАЧАЛЬНИК:  (пауза)
НАЧАЛЬНИК:  Сейчас.
        [считает]
        [долго]
        [ПЯТНАДЦАТЬ СЕКУНД реального времени]
        [игрок не может прервать]
НАЧАЛЬНИК:  Тридцать шесть тысяч пятьсот двадцать четыре.
        [пауза]
НАЧАЛЬНИК:  Но это неважно.
НАЧАЛЬНИК:  Главное — пункт работает.
```

**Третий смех не приходит.**

Игрок считает в уме. Сто лет.

## 13.4 Что он даёт

```
НАЧАЛЬНИК:  Вам куда?
ЯР:         (пауза)
ЯР:         Я не знаю.
НАЧАЛЬНИК:  Так не бывает. Всем куда-то.
ЯР:         Мне брата найти.
НАЧАЛЬНИК:  (пауза)
НАЧАЛЬНИК:  Это не станция. Это человек.
ЯР:         Ну да.
НАЧАЛЬНИК:  (очень долгая пауза)
НАЧАЛЬНИК:  ...это сложнее.
```

```
НАЧАЛЬНИК:  На востоке город.
ЯР:         Город?
НАЧАЛЬНИК:  Так говорят. Я не был. Далеко.
ЯР:         Там люди?
НАЧАЛЬНИК:  Не могу знать. Не моя зона обслуживания.
ЯР:         Но кто-то там есть?
        [пауза]
НАЧАЛЬНИК:  Оттуда иногда слышно.
```

**[[Яр]] узнаёт о существовании [[Депо]] в акте II.**
С этого момента у него есть цель.

Он даёт:
- **карту**, нарисованную от руки, неточную, трогательную;
- направление на [[Водокачка|Водокачку]];
- **отметку** — пункт «Ничего» становится точкой сохранения.

## 13.5 Смех

Есть один вариант диалога, где [[Яр]] **смеётся**.
Один раз за всю игру.

Запускается, если игрок спросил про урну **и** про скамейку
**и** про подметание — то есть проявил интерес к абсурду.

```
НАЧАЛЬНИК:  ...и по инструкции я обязан объявлять прибытие.
ЯР:         Кому?
НАЧАЛЬНИК:  Присутствующим.
ЯР:         Тут никого нет.
НАЧАЛЬНИК:  Сейчас есть вы.
        [пауза]
НАЧАЛЬНИК:  (выпрямляется, поправляет фуражку)
НАЧАЛЬНИК:  Внимание. Остановочный пункт «Ничего».
НАЧАЛЬНИК:  Стоянка одна минута. Не задерживайтесь.
        [пауза]
ЯР:         ...
ЯР:         (коротко, будто закашлялся)
ЯР:         Ха.
        [он сам пугается этого звука]
        [пауза]
ЯР:         Извините.
НАЧАЛЬНИК:  Ничего. Мне приятно.
```

**Держать эту сцену любой ценой.**

## 13.6 Проводник

Если [[Проводник]] уже появился (акт III+), при повторном визите:

```
НАЧАЛЬНИК:  (Яру) Вы хорошо держитесь.
НАЧАЛЬНИК:  Один-то.
```

[[Проводник]] стоит в двух метрах.

**Яр не переспрашивает.**

Начальник **не видит его**. Он ни разу за игру не обращается
ко второму, даже если игрок специально пытается.

См. [[Проводник#Улики за то, что он выдумка]].
