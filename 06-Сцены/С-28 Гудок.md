# С-28 · ГУДОК

**[[Акт IV — Гудок]]. Лучшая сцена игры. ~6 минут. Ни одной реплики
в главной части.**

## 28.1 Ожидание

Конец отрезка [[Тим]]а. Крыша [[Багажное отделение|Багажного]].
Ночь. Внизу весь город. На западе темнота.

```
        [Тим свистит]

ТИМ:    ··

        [эхо уезжает на запад]
        [ждёт]
        [ждёт]
        [ждёт]
```

**Сорок секунд.** Кнопки не работают. Камера не двигается.
Музыки нет.

Игрок сидит и смотрит на темноту.

▶ **ПЕРЕКЛЮЧЕНИЕ #7** — прямо посреди ожидания.

## 28.2 Ответ

Конец отрезка [[Яр]]а. [[Насыпь]]. Ночь. Костёр.

```
        [Яр не спит]
        [сидит]

        [и тогда — с востока, издалека, через триста километров:]

        ··

        [Яр садится. Медленно.]

ЯР:     ...
ЯР:     (встаёт)
ЯР:     Это...
```

▶ **ПЕРЕКЛЮЧЕНИЕ #8**

## 28.3 Разговор

**Разделённый экран.** Единственный раз до [[Акт VI — Горловина]].

```
  ┌──────────────────────┬──────────────────────┐
  │       НАСЫПЬ         │        ДЕПО          │
  │                      │                      │
  │        ЯР            │        ТИМ           │
  │      стоит           │   сидит на краю,     │
  │   смотрит на восток  │   обхватив колени    │
  │                      │   (уже не ждёт)      │
  └──────────────────────┴──────────────────────┘
```

**Игрок управляет Яром.** [R].

```
ЯР:     ··
```

Пауза. Долгая. Звук уезжает.

```
                                 [ТИМ поднимает голову]
```

Пауза.

```
                                 ТИМ:  ...
                                 ТИМ:  ··
```

Пауза.

```
ЯР:     ··
                                 ТИМ:  ··
ЯР:     ··
                                 ТИМ:  ··
```

**И тогда управление отдаётся обоим сразу.**

Игрок жмёт [R] — и **свистят оба**. Одновременно.
Быстрее. Ещё быстрее.

```
ЯР:  ··         ТИМ:  ··
     ··               ··
     ··               ··
   ····             ····
   ······           ······
```

Экран заполняется сигналами. Оба смеются. Оба плачут.
Ни одного слова.

**Полторы минуты.** Никакого текста. Никаких субтитров.
Игрок может свистеть сколько хочет — сцена не кончится,
пока он не остановится сам.

## 28.4 Флешбэк

**Единственный флешбэк в игре. Три секунды.**

```
        [пиксельная квартира. Коридор. Ночь.]
        [закрытая дверь спальни. Из-под неё свет.]
        [два мальчика по разные стороны стены.]
        [нельзя шуметь.]

        [стук в стену:  · ·]
        [стук в ответ:  · ·]
```

И всё. Возвращаемся.

**[[Мать]] не показана.** Только свет из-под двери.
См. [[Мать#Правило]].

Игрок теперь понимает [[Свистковая азбука|азбуку]] по-настоящему:
`··` — это не «я здесь». Это «**мы не одни**».

---

## 28.5 Решения

Разделённый экран. Оба говорят вслух, одновременно, разное.

```
        ЯР:                      ТИМ:

    Он там.                  Он идёт.
    Я дойду.                 Он правда идёт.
    Я его заберу.            Надо, чтобы ему было куда прийти.
    Мы поедем домой.         Надо, чтобы тут всё было хорошо.
```

Реплики появляются **попеременно**, с наложением.
Слушая по отдельности — оба правы.
Слушая вместе — **они уже спорят**, не зная об этом.

```
        ЯР:                      ТИМ:

    Три недели.              Сорок дней.
    Успею.                   Успею.
```

**Одно и то же слово. Про противоположное.**

## Технические заметки

- **Свисток игрока не квантуется.** Свистит ровно тогда,
  когда нажал. Ритм — его.
- **Эхо реальное**, а не сэмпл: движок обрабатывает свист игрока
  задержкой и фильтром, и возвращает.
- В [[Кооп|коопе]] два игрока свистят друг другу через экран.
  Это единственное место, где кооп **лучше** одиночной игры.
- Ускорить нельзя. Пропустить нельзя. Кнопка пропуска не работает
  всю сцену.

---

## Правило

Это самая дорогая эмоция в игре, и она стоит нам **двух нот
и разделённого экрана**.

Не добавлять оркестр. Не добавлять слова. Не добавлять крупных планов
лиц. Не добавлять слёз на спрайтах.

**Чем меньше, тем сильнее.**
