# БОСС — МИММИ

**Первый бой [[Дали]] за всю игру. Третий час прохождения.
Она зовёт голосом его брата.**

Терпение: 60. ~11 минут в первый раз.

♪ *(нет музыки — только эхо в воронке)*
Музыка появляется **после** боя, и это первая мелодия
на маршруте Дали за три часа.

---

## До этого

Два акта — ни одного живого существа.
Восемь дней [[Шарра|пустыни]], потом [[Стеклянный лес]],
где у него **отняли смех** так, что он не заметил.

Игрок хочет встретить кого угодно.

## Завязка

[[Провалы]]. Темно. Дали спускается по осыпи в третью воронку.

И снизу:

```
    (детский голос, далеко, с эхом)
    Дали?
```

**Управление отключается на две секунды.**

```
    Дали, ты?
    Дали, я тут!
    Дали, мне тут плохо!
```

Игрок **не слышал этот голос два часа** — с [[Пролог — Ночной поезд|пролога]].

Дали бежит. Игрок бежит. Никакой кнопки «не бежать» нет.

---

## Экран боя

Не обычный. **Дали не видит противника.**

```
  ┌────────────────────────────────────────────────────┐
  │                                                    │
  │                    (темнота)                       │
  │                                                    │
  │        ...где-то там, снизу, кто-то плачет         │
  │                                                    │
  │  ┌──────────────────────────────────────────────┐  │
  │  │                                              │  │
  │  │            ОКНО (тёмное)                     │  │
  │  │                  ▪                           │  │
  │  └──────────────────────────────────────────────┘  │
  │                                                    │
  │  ЧАСТИ  ✔✔✔✔✔✔✔✔✔✔✔✔                              │
  │                                                    │
  │  [ГОВОРИТЬ]  [ИСКАТЬ]  [СЛУШАТЬ]  [УЙТИ]          │
  └────────────────────────────────────────────────────┘
```

**Полосы терпения нет** — он не знает, с кем говорит.

---

## Фаза 1 — «Он тут» (первые 3 минуты)

Ходы:

| Ход | Что делает |
|---|---|
| **ГОВОРИТЬ** | Дали отвечает. **Каждый ответ — ошибка**: она подстраивается |
| **ИСКАТЬ** | спуск глубже. Темнее. Эхо сильнее |
| **СЛУШАТЬ** | **правильный ход**. Слышно, что голос идёт **сразу с трёх сторон** |
| **УЙТИ** | работает. Она пойдёт следом. Через час догонит |

Мимми говорит. Игрок слушает голос [[Ови]], которого не слышал два часа.

```
    Дали, я тут давно.
    Тут холодно.
    Я тебя звал, ты не пришёл.
        [пауза]
    Ты почему не пришёл?
```

**Это бьёт по игроку сильнее, чем по Дали.**
Игрок последние два часа играл за Ови и знает, что тот в порядке.
Дали — нет.

## Фаза 2 — «Качели» (3–7 минут)

Она достаёт **детали**.

```
    Дали, помнишь качели?
    Которые сломанные, во дворе.
    Ты меня качал, а я боялся.
    А ты сказал, что не отпустишь.
        [пауза]
    Ты не отпустил.
```

**Игра ни разу не показывала качели.** Ни в прологе,
ни во флешбэке, нигде.

Дали верит окончательно.

### Что это на самом деле

Она купила голос [[Ови]] у [[Фартинг]]а **вместе с обрывком памяти**.

[[Ови]] отдал этот кусочек [[Трабб]]у на [[Ярмарка|Ярмарке]]
за какую-то ерунду. **Смеясь.**

**Игрок видел эту сцену.** В том же акте, за сорок минут до этой.

## Фаза 3 — «Дай попробовать» (7–11 минут)

Она просит еду. Голосом голодного ребёнка.

```
    Дали, у тебя есть что-нибудь?
    Я три дня не ел.
```

Дали протягивает. Она берёт.

И **протягивает в ответ**:

```
    На. Ты тоже поешь.
    Ты же не ел.
```

> **выбор:**
> ├ **Взять и попробовать** → она забирает **ВКУС**
> ├ **Отказаться** → она просит ещё раз, обиженно, детским голосом.
> │   На третий отказ она **выходит** — и тогда её видно,
> │   и бой становится обычным, и его можно выиграть
> └ **`[СЛУШАТЬ]`** ⟵ единственный по-настоящему верный

### Ход `СЛУШАТЬ` на этой фазе

```
        [Дали перестаёт отвечать]
        [слушает]
        [пауза — восемь секунд, самая долгая в акте]

        [голос продолжает говорить в темноте]
        [и в нём слышно: он повторяется]
        [одна и та же интонация. Третий раз.]

ДАЛИ:   ...
ДАЛИ:   Ови?
        [пауза]
ДАЛИ:   Как меня зовут?
        [пауза]
        [долгая пауза]
    Дали.
ДАЛИ:   Полностью.
        [пауза]
        [очень долгая пауза]
    ...Дали.
```

**Она не знает.** Она купила голос, а не человека.

---

## Что происходит

Как бы игрок ни прошёл — Мимми **выходит на свет**.

Маленькая, сгорбленная, в свалявшемся пуху.
Вместо лица — воронка, прикрытая лапой.

И **продолжает говорить голосом Ови**, глядя ему в глаза.

```
МИММИ:  (голосом Ови)
МИММИ:  Ну ты чего.
МИММИ:  Я же тут.
        [пауза]
МИММИ:  (своим — сухим, шелестящим, без выражения)
МИММИ:  Вкусно было?
        [пауза]
МИММИ:  Уже нет.
```

И уходит. **Боком.**

Продолжая **смеяться голосом брата**, всё дальше,
и смех отражается в воронках ещё минуту после её ухода.

Игрок стоит и слушает.

---

## Что теряется

- **ВКУС** — если попробовал.
- **Ничего** — если раскусил.

Но потеря — не главное.

---

## Что появляется

**Новая опция в диалогах. Навсегда.**

```
    [НЕ ВЕРИТЬ]
```

Она доступна **везде и на всех**: на [[Хлюп]]е, на [[Лорель|Лореле]],
на любом NPC, на любой реплике.

Игра **не объясняет**, что она делает.
Она просто есть, серая рамка внизу списка.

И в [[Акт VII — Улей]], когда [[Ови]] позовёт брата
по-настоящему, она будет там же.

---

## Хвост

Дали разводит костёр в воронке. Один.

```
ДАЛИ:   ...
ДАЛИ:   (достаёт узелок из кармана — тот, из акта I)
ДАЛИ:   (смотрит)
ДАЛИ:   (узелок дышит)
        [пауза]
ДАЛИ:   Ты чей?
        [пауза]
ДАЛИ:   (кладёт обратно)
ДАЛИ:   Ладно. Так.
```

**Третье «Ладно. Так.»**

▶ **ПЕРЕКЛЮЧЕНИЕ #6**

---

## Ассист

- голос не отключается (это сюжет);
- ход `СЛУШАТЬ` подсвечивается после второй фазы;
- потерю ВКУСА можно отменить в настройках доступности
  («не терять части в сюжетных боях»).

**Сама сцена не смягчается.** Никогда.

---

## Правило

Мимми **не выглядит страшной**. Ни клыков, ни когтей,
ни красных глаз. Маленькая, потрёпанная, жалкая.

Страшно **только то, что она говорит**.

Если художник нарисует монстра — сцена умрёт.
