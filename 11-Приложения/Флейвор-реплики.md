# Флейвор-реплики

**~900 реплик фоновых NPC.** Здесь — образцы каждой категории
и правила написания остальных.

---

## Правило №1

> **Каждый NPC однажды говорит то, что игрок вспомнит в финале.**

Даже проходной смазчик. Не «мудрость» — **бытовая фраза,
которая станет тяжёлой позже**.

---

## Правило №2

Реплики **меняются** при трёх условиях:
1. акт (по мере сюжета);
2. вписан ли этот NPC в [[Ведомость (механика)|Ведомость]];
3. состояние города (стук с запада, распоряжение, отречение).

Итого до **4 наборов** на персонажа. Отсюда объём.

## [[Первый путь]] · работяги

### Смазчик
```
    Смазал. Теперь если поедет — поедет тихо.
```
```
    Букса греется. Ни у кого не греется, а у меня греется.
    Я к ней привык.
```
```
    Ты масло не трогай. Масло я сорок лет одно и то же беру.
    Ну, беру — громко сказано. Оно не кончается.
```
**Вписан:**
```
    Слушай. А ведь поедет.
    Я всю жизнь смазывал, чтоб поехало.
    А теперь думаю: а вдруг я плохо смазал.
```

### Уборщица перрона
```
    Ноги вытри.
```
```
    Я тут мету. Ты видишь, что я мету?
    Значит, и мети, где я не мету.
```
```
    Чисто. Всегда чисто. Сорок лет чисто.
    (пауза)
    Сто.
```
**Вписана:**
```
    Я подумала — а надо ли мести.
    И знаешь что? Надо.
    Только теперь по-другому надо.
```

### Диктор
```
    Голос берегу.
```
```
    Я в шесть говорю. Больше не говорю.
    Иначе привыкнут.
```
```
    Хочешь, объявлю тебя?
    (объявляет)
    Ну вот. Теперь ты объявленный.
```

### Кассир
```
    Билетов нет. Приходите завтра.
```
*(единственная реплика до акта VII)*

## Реакции города на сюжет

### После первого стука (акт III)
```
    Слышал?
    — Что?
    — Вот. Опять.
    — ...это молоток?
    — Это молоток.
```
```
    Сто лет ничего не стучало. Сто лет.
```
```
    (Башня) Установить производителя несанкционированных работ.
```

### После первого имени (акт III)
```
    Она спала. Я сам видел. Она спала.
```
```
    Он написал, и она спала.
    — И что?
    — Ты не понимаешь. ОНА СПАЛА.
```

### После распоряжения (акт V)
```
    Мальчика назначили.
    — Кем?
    — Тем самым.
    — ...ему одиннадцать.
    — Ну. Назначили же.
```

### После отречения (акт VI, вариант В — крик)
```
    (тихо) Он на нас накричал.
```
```
    Он правильно накричал.
    Я бы тоже накричал, если б на меня так смотрели.
```
```
    (Песочница, прячась) Я не хотела.
```

## Как писать оставшиеся ~800

1. **Одна мысль на реплику.** Не больше трёх строк.
2. **Бытовое, не философское.** Философия получится сама.
3. **Никаких намёков на игрока.** NPC не знают, что они в игре.
4. **Проверка:** можно ли эту реплику вспомнить через десять часов
   и почувствовать что-то новое? Если нет — переписать.
5. **Второй набор (вписанный)** обязателен. У него всегда есть
   **будущее время**: «а вот когда поедем», «я потом», «завтра».

Именно появление будущего времени в речи — главный маркер того,
что [[Ведомость (механика)|Ведомость]] работает.
